# 数字人陪伴 App 页面功能列表

| 项目 | 内容 |
| --- | --- |
| 版本 / 日期 | V1.1 / 2026-11-09 |
| 平台 | Android、iOS |
| 底部导航 | 首页、我的 |
| 设计依据 | 首页参考用户提供的数字人卡片页面；我的参考用户提供的个人资料与历史卡片页面 |
| 界面语言 | 简体中文、English，默认跟随系统，可手动切换 |
| 关联需求 | [PRD V1.2](./PRD.md) |

## 1. 页面结构

仅首页和我的显示底部 Tab；二级页面和全屏通话页隐藏 Tab，通过返回回到原入口。返回首页时保留列表位置。

```text
首页
├── 我的数字人
│   ├── 新增 / 编辑数字人
│   │   ├── 音色选择面板
│   │   └── 知识库管理
│   └── 数字人详情
│       ├── 编辑数字人
│       ├── 动作面板（管理模式）
│       ├── 记忆管理
│       └── 实时通话
│           ├── 动作面板（互动模式）
│           └── 音色选择面板
└── 推荐数字人（内置模板）
    └── 数字人详情 → 使用模板并保存到我的数字人

我的
├── 账号设置
├── 历史记录
│   └── 历史详情
└── 设置
```

账号设置保留当前“用户自填 Vidu Key、无自建登录系统”的方案，管理本地资料与接入配置。下文“模型图片”指数字人的形象原图，不是要求用户选择大语言模型。

## 2. 页面与面板总表

共 13 个功能界面：2 个 Tab 主页面、9 个二级页面、2 个复用面板。头像编辑、图片选择、文字输入和删除确认采用系统选择器或弹窗，不单独计页。

| 编号 | 页面 / 面板 | 主要入口 | 核心功能 |
| --- | --- | --- | --- |
| P01 | 首页 | 底部“首页” | 展示我的数字人、创建入口、内置推荐数字人；查看详情、发起通话、编辑、复制、删除 |
| P02 | 我的 | 底部“我的” | 本地头像、昵称、简介；账号设置；最近历史卡片与全部历史入口；设置入口 |
| P03 | 新增 / 编辑数字人 | 首页新增卡片、数字人更多菜单、详情 | 名称、提示词、知识库、模型图片；音色、简介、开场白、记忆开关；保存草稿和保存配置 |
| P04 | 数字人详情 | 首页数字人封面 | 大图、名称、简介、声音和配置摘要；开始通话、编辑、动作管理、记忆管理；模板使用 |
| P05 | 音色选择面板 | 数字人编辑、通话声音按钮 | 查看兼容音色、选择、已有素材试听、确认；通话内展示切换结果 |
| P06 | 知识库管理 | 数字人编辑中的知识库项 | 选择已有库、新建库、文档 URL 导入、查看处理状态、绑定 / 解绑、删除文档 / 库 |
| P07 | 记忆管理 | 数字人详情 | 当前数字人记忆开关、查看与刷新记忆、清空该角色云端记忆 |
| P08 | 实时通话 | 数字人卡片或详情的“聊天 / 开始通话” | 数字人视频、实时语音、字幕、文字输入、动作、静音、音频输出、声音切换、打断、挂断 |
| P09 | 动作面板 | 通话动作按钮、详情动作管理 | 预置动作、输入动作描述、发送、收藏；管理模式支持新增、编辑、排序与删除 |
| P10 | 历史记录 | 我的“查看全部” | 按时间展示本机通话，按数字人筛选；查看详情、删除本地记录 |
| P11 | 历史详情 | 历史卡片 | 当次角色信息、时间、时长、状态、对话文本、用量；再次通话、删除本地记录 |
| P12 | 账号设置 | 我的资料区“账号设置” | 编辑本地头像、昵称、简介；输入 / 修改 / 检查 / 清除 Vidu Key，选择保存方式 |
| P13 | 设置 | 我的右上角设置按钮 | 语言、通话与字幕偏好、备份恢复、缓存清理、诊断导出、隐私说明、关于应用 |

## 3. 首页 P01

### 3.1 页面布局

参考图一的深色背景、顶部横幅、分区标题和两列图片卡片。顶部横幅使用自己的产品介绍与素材，点击不自动开启实时会话。

| 区域 | 展示内容 | 用户操作 |
| --- | --- | --- |
| 顶部介绍 | 产品名称、陪伴介绍横幅 | 浏览产品介绍 |
| 我的数字人 | 新增卡片固定首位，后续展示自建或从模板保存的数字人 | 新增、打开详情、开始通话 |
| 数字人卡片 | 模型图片、名称、简介、可用状态、“聊天”按钮、更多菜单 | 点封面进入详情；点聊天创建实时通话；更多中编辑、复制、删除 |
| 推荐数字人 | 自有素材制作的内置模板，展示图片、名字、性格简介 | 查看详情、使用模板，保存为自己的数字人后发起通话 |
| 底部导航 | 首页、我的 | 切换主页面 |

推荐区用于选择 Vidu 平台提供的官方形象。目录使用用户提供的 Vidu 官网只读 roles 接口，匿名读取已验证；接口隔离封装，不携带 API Key 或浏览器 Cookie。网站角色 ID 与公开 API avatar ID 不混用，选用图片后创建账号自己的 API 形象资产。用户选用后生成独立本地角色、character ID 与记忆分区。性格模板与官方形象分开管理。

### 3.2 状态与交互

- 没有自建数字人时仍显示新增卡片和推荐模板。
- 草稿、形象处理中、处理失败、可通话、形象需更新分别展示；未就绪卡片引导补齐配置。
- 未配置 Key 可浏览模板、填写并保存本地草稿；需要云端操作时引导到账号设置，返回后保留编辑内容。
- 浏览首页、滚动卡片、打开详情均不创建实时会话；只有明确点击聊天或开始通话才创建。
- 删除、复制和进入编辑从更多菜单操作，卡片主体突出形象与聊天入口。

## 4. 新增 / 编辑数字人 P03

### 4.1 主要字段

| 字段 | 要求 | 功能与展示 |
| --- | --- | --- |
| 名称 | 必填，建议 1～30 字符 | 数字人姓名，用于首页卡片、通话和历史 |
| 提示词 | 必填 | 多行输入身份、性格、背景、关系、语气与互动要求；支持从模板填入并修改 |
| 知识库 | 可选，首版一个角色绑定一个库 | 显示未绑定或库名称；进入选择、新建与资料管理 |
| 模型图片 | 可通话时必填 | 从相册选择单人形象图，预览、替换，展示云端处理结果；保留本地原图 |

### 4.2 其他已确认配置

| 字段 | 交互 |
| --- | --- |
| 简介 | 可选短描述，用于首页卡片与详情 |
| 音色 | 默认选择兼容音色，点击打开声音面板 |
| 开场白 | 可选，设置每次通话开始的问候内容 |
| 记住我们的对话 | 按角色开关，说明开启后使用云端长期记忆 |
| 动作风格 | 收入更多设置，不占据主要表单区域 |

表单按“名称 → 模型图片 → 提示词 → 知识库 → 声音与更多设置”组织。提示词是主要人设编辑区，避免强制用户再填写一整套重复的性格、身份和背景字段。

底部提供“保存草稿”和“保存数字人”。草稿允许缺少必要项；保存为可通话配置时校验名称、提示词、图片状态和音色兼容性。保存后返回首页并更新卡片，不自动拨打。编辑未保存离开时提示保存或放弃；本次已有通话不因编辑而自动重建。

## 5. 我的 P02

### 5.1 页面布局

参考图二的居中头像、昵称、简介、宽按钮和历史图片卡片，将内容限定为账号、历史与设置。

| 区域 | 展示内容 | 用户操作 |
| --- | --- | --- |
| 右上角 | 设置图标 | 打开设置 |
| 资料区 | 本地头像、昵称、个人简介 | 通过下方账号设置编辑 |
| 账号设置按钮 | 宽按钮；可显示已配置 / 未配置的接入状态 | 编辑资料，管理 Vidu Key |
| 历史记录标题 | “历史记录”与“查看全部” | 进入完整历史列表 |
| 最近历史卡片 | 角色图片与名称、通话时间、时长、状态 | 查看详情；更多菜单删除本地记录 |
| 底部导航 | 首页、我的 | 切换主页面 |

本地资料不冒充 Vidu 平台返回的用户名或账号认证信息；没有已核实的账号查询能力时，不展示虚构的平台用户 ID、余额或会员状态。

### 5.2 历史的展示规则

- 卡片使用通话时的数字人图片和名字快照，之后修改或删除数字人不改写旧记录的归属展示。
- 状态显示已结束、连接失败或待核对；记录正文展示当次保存的对话文本。
- 未获取最终用量时显示“用量待更新”，避免用本地退出代替平台结束确认。
- “再次通话”使用该角色当前配置，并需要用户确认开始新的一场会话；角色已删除则关闭此操作。
- 首版沿用对话文本与通话记录，不把截图中的“直播回放 / 离线数字人 / 生成中”作为功能入口，也不展示没有录制资源的播放按钮。
- 无历史时显示简短引导，点击“去首页”选择数字人。

## 6. 通话及角色附属功能

| 功能 | 所在界面 | 规则 |
| --- | --- | --- |
| 实时陪伴 | 全屏通话 | 画面以数字人为主；用户只上传麦克风，默认不开自身摄像头 |
| 文字交流 | 通话内输入区 | 与语音属于同一实时会话；不额外增加独立纯文字聊天页面 |
| 动作互动 | 动作面板互动模式 | 点击预置动作或输入动作描述发送，支持收藏；显示已发送状态 |
| 动作管理 | 数字人详情进入同一面板的管理模式 | 编辑、排序、删除收藏；未通话时不提供发送按钮 |
| 知识资料 | 编辑数字人 → 知识库管理 | 首版从文档 URL 导入，展示处理状态；不是直接提交手机本地文件路径 |
| 长期记忆 | 数字人详情 → 记忆管理 | 按当前角色查看与清空；与本地历史删除分别处理 |
| 声音选择 | 编辑数字人与通话内共用面板 | 只提供当前模式兼容音色；有素材才显示试听；通话内切换展示生效状态 |

连接中、失败、恢复、结束等状态在通话页内呈现，不额外拆成多个导航页面。返回或挂断需要遵循 PRD 的结束策略，防止只离开画面而遗漏云端会话处理。

## 7. 账号与设置的职责

| 界面 | 包含内容 |
| --- | --- |
| 账号设置 | 本地头像、昵称、简介；Vidu Key 的输入、显隐、修改、只读连接检查、保存方式、清除凭证 |
| 设置 | 语言（跟随系统 / 简体中文 / English）；字幕显示、通话提醒和默认音频偏好；角色与身份备份恢复；缓存清理；脱敏诊断导出；隐私与权限说明；关于与版本 |

清除 Key 不删除角色、历史或云端记忆；缓存清理不删除角色原图和聊天数据库。备份导出明确列出实际包含的数据，默认排除 Key。首版不因“账号”入口引入手机号注册、短信登录或云端自动同步。

语言选择使用设置内的选择面板，不增加 Tab 或主页面。首次跟随系统，匹配 zh / en，其他语言回退英文；手动选择即时生效并持久化。界面翻译覆盖按钮、错误、空态、模板说明与无障碍标签，用户角色、提示词、资料、记忆与对话原文保留；切换语言不清空编辑内容、不重启通话。

| 中文入口 | 英文入口 |
| --- | --- |
| 首页 / 我的 | Home / Me |
| 新增数字人 | Create Avatar |
| 账号设置 / 历史记录 / 设置 | Account Settings / History / Settings |
| 语言 / 跟随系统 | Language / System Default |

中英文界面使用同一信息结构，允许英文换行和按钮宽度变化。界面英文不代表所有音色均支持英文对话，声音兼容性另行验证。

## 8. 关键路径与验收

1. 新增路径：首页 → 新增数字人 → 填名称、提示词、图片，可选知识库 → 选择声音 → 保存 → 首页显示新卡片。
2. 陪伴路径：首页 → 数字人聊天按钮 → 检查配置与权限 → 进入全屏通话 → 语音 / 文字 / 动作互动 → 挂断 → 我的查看记录。
3. 资料路径：我的 → 账号设置 → 编辑本地资料 / 配置自己的 Key → 保存 → 返回原流程。
4. 知识路径：编辑数字人 → 知识库 → 导入文档 URL 并等待处理 → 绑定 → 下次通话使用。
5. 记录路径：我的 → 最近卡片或查看全部 → 历史详情 → 阅读对话或再次通话。

验收时确认底部仅有首页和我的；我的中只有账号、历史、设置内容；创建表单包含用户要求的四个主要字段；通话与动作能力可从首页数字人进入；所有卡片、字段与状态在 Android / iOS 上保持一致。

双语验收覆盖全部 13 个界面、语言选择面板、系统跟随、重启保留、长英文与大字号；切换后草稿、角色 ID、历史和活动通话均保持。
