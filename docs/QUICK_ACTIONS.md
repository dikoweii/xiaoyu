# 通话快捷动作

键盘面板默认打开常用分类。分类与动作各占一行，分别左右滑动；切换分类从首项开始。动作按钮仅显示文字，聊天输入发送普通文字；动作沿用 type 101 和两秒冷却；成功发送不显示提示文字，仅在发送失败或触发冷却时显示错误。

常用：比心、挥手、微笑、点头、抱抱、飞吻、比耶、鼓掌。常用引用下方目录中的同一动作，不重复维护描述。

共 106 个独立动作：用户提供的 104 条合并“别发/头发别到耳后”一组，保留微笑、点头并增加普通比耶，共 106 项。“捧脸杀/捧脸”明确为双手/单手；眨眼和眨眼比耶分别保留。道具、吃喝、穿搭及连续动作的画面效果尚待真实通话验证。

维护入口：[分类与稳定 ID](../lib/presentation/quick_actions.dart)，[中文名称和完整描述](../lib/l10n/app_zh.arb)，[英文翻译](../lib/l10n/app_en.arb)。新增动作需同步 ID、分类和双语 ARB，通过 flutter gen-l10n 生成代码，不手改 generated 文件。无需改动页面或新增图标。
